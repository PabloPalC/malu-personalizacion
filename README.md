# Malú · Web de personalización

Propuesta de web nueva para **Malú** (antes Krea Impresión 3D), Cartagena.
Impresión 3D, camisetas personalizadas, ropa laboral y regalos publicitarios.

**Demo:** https://pablopalc.github.io/malu-personalizacion/

## Stack
HTML + CSS + JS vanilla. Sin dependencias. Fuentes Outfit / DM Sans (Google Fonts).
